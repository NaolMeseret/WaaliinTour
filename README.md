## About

Waalin Tours is an AI-powered platform connecting tourists to authentic cultural experiences while empowering resorts to increase revenue. Our platform combines guided tours, interactive learning, and an AI assistant to provide a seamless, safe, and educational cultural journey.

---

## Problem

Tourists and resorts face challenges in cultural tourism:

- **Tourists:**
  - Hard to find authentic experiences
  - Language barriers & safety concerns
  - Disconnected from local culture

- **Resorts:**
  - Low occupancy during off-season
  - Limited revenue streams beyond rooms & services

---

## Solution

Waalin Tours bridges the gap with:

1. **Team Cultural Tours:** Guided, safe, and social experiences
2. **Interactive Cultural Learning:** Listen, speak, and get scored on local languages
3. **AI Assistant:** Ask anything about local culture for instant guidance
4. **Revenue System for Resorts:** Generate income beyond standard bookings

---

## Key Features

- **Interactive Language Learning:**

## Installation

```bash
# Clone the repository
git clone https://github.com/NaolMeseret/WaaliinTour.git

# Navigate to the project folder
cd waalin-tours

# Install dependencies
npm install

# Start the development server
npm run dev
```
